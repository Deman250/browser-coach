# browser-coach

A client-side coaching tool that turns a day's sleep, water, steps, and training numbers into a HIT or MISS verdict, with a direct, no-nonsense coaching message. Runs entirely in the browser, no backend or API key required.

## What it does

- Takes sleep, water, steps, bench weight, and cold-shower status as input
- Checks each against a goal threshold and calls the day a HIT or MISS
- Picks a coaching message from a template pool based on which factor(s) fell short
- Logs each entry to a running session log

## Try it

Open `index.html` in any browser, or visit the live page: **https://deman250.github.io/browser-coach/**

## Tech

HTML, CSS, JavaScript. No dependencies, no build step.
